# Moni 3D

Captura de un cuarto hecha con Scaniverse (`moni.ply`, nube de 294 mil puntos con color) montada en la web con three.js + WebXR para verse en Meta Quest.

**Ver:** https://elfidelon.github.io/moni-3d/

## Controles

| Dónde | Control |
|---|---|
| Meta Quest | **Entrar a VR** · stick izquierdo moverse (gatillo = más rápido) · stick derecho girar 30° y subir/bajar · **A** volver al inicio |
| PC | Orbitar: arrastrar / rueda / clic derecho · Caminar: WASD, Q/E, Shift · "Puntos" cambia el tamaño |
| Celular | Arrastrar, pellizcar, dos dedos |

## Modelo

`models/moni.ply` (4.4 MB) es el archivo original sin cambios. Viene en metros con Z hacia arriba; el visor lo gira para que Y sea arriba.
